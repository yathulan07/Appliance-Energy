# Appliance Energy Consumption Website

## Project Overview

This project is a small interactive website developed for COS30045 Data Visualisation.

The purpose of this website is to demonstrate the use of HTML, CSS and JavaScript to create an interactive web-based application about appliance energy consumption in the Australian market.

## Website Features

The website contains three sections:

- Home
  - Provides an introduction to appliance energy consumption and energy efficiency.

- Televisions
  - Displays placeholder information about television energy usage.

- About Us
  - Provides information about the project purpose and development technologies used.

## Technologies Used

- HTML
  - Used to create the structure and content of the website.

- CSS
  - Used to design the layout, colours and styling.

- JavaScript
  - Used to create interactive navigation between pages.

- GitHub
  - Used for version control and storing project files.

- Vercel
  - Used for website deployment.
